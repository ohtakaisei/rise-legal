利用規約

制定日：2026年9月29日　最終改定日：2026年9月29日

この利用規約（以下「本規約」）は、ohtakaisei（個人開発者。以下「運営者」）が提供する iPhone 向けゲームアプリ「RISE」（以下「本アプリ」）の利用条件を定めるものです。本アプリをダウンロード・利用した時点で、本規約に同意したものとみなします。本規約に加えて、Apple の標準使用許諾契約（Licensed Application End User License Agreement）が適用されます。

第1条（本アプリの内容）

本アプリは、バスケットボールの選手を育成し、試合を行うゲームです。「高校編」「プロ編」「球団オーナー」などのモードがあり、一部のモード・機能はアプリ内課金により利用できます。

第2条（アプリ内課金）

  1. アプリ内課金の決済は Apple Inc. の App Store を通じて行われ、価格は購入画面に表示された金額（税込）です。
  2. 買い切りの商品（例：本編、コンプリートパック、シグネチャームーブ、モーションスタイル）は、購入した Apple ID で本アプリを利用する限り使い続けられ、「購入を復元」で再び有効にできます。
  3. 消費型の商品（例：能力ポイント、技の書、引き直し券、やり直し券、装備パック）は、使用すると消費されます。消費型の商品は復元できず、アプリを削除すると失われます。
  4. アプリ内の通貨・アイテム・能力などは、ゲーム内でのみ利用できるもので、現金や他のサービスとの交換・払い戻し・譲渡はできません。
  5. 購入後の返金は、Apple の定める手続き（reportaproblem.apple.com）に従います。運営者が直接返金を行うことはできません。

第3条（自動更新サブスクリプション「RISE パス」）

名称RISE パス
期間と料金1か月ごと（料金は購入画面に表示される金額。日本では月額 680 円・税込）
内容プロ編のプレイ（球団オーナーはプロ編の中で解放）、高校編 2・3 年目のプレイ、作戦（プレイブック）の登録枠 +2、経験点 1.3 倍、装備が出やすくなる、毎日のログインボーナス
自動更新期間の終了の 24 時間前までに解約しない限り、自動的に更新され、Apple ID に請求されます。
解約方法iPhone の「設定」→ 名前 →「サブスクリプション」から、いつでも解約できます。解約後も、支払い済みの期間の終わりまで利用できます。期間の途中での解約による日割りの返金はありません。
期限切れのときRISE パスが切れても、プロ編などのセーブデータは端末に残り、再び加入すると続きから遊べます。
