RISE

プライバシーポリシー

制定日：2026年9月29日　最終改定日：2026年9月29日

ohtakaisei（個人開発者。以下「運営者」）は、iPhone 向けゲームアプリ「RISE」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 基本方針

本アプリは、アカウント登録を必要とせず、氏名・メールアドレス・電話番号・住所・位置情報・連絡先・写真などの個人情報を収集しません。広告や、利用者を追跡する分析ツール（トラッキング）も使用していません。

2. 端末（とお客様自身の iCloud）に保存する情報

情報内容保存場所
ゲームの進行データ作成した選手の名前・見た目・能力、試合の成績、所持アイテム、コイン、レガシー、設定（音・操作方法など）お使いの端末の中（暗号化して保存）。iCloud にサインインしている場合は、機種変更や iPhone と iPad の行き来のために、暗号化したままお客様自身の iCloud（Apple の iCloud キー値ストア）にも保存します。運営者がこのデータを見ることはできません。
購入の状態購入済みの商品、RISE パスの有効期限お使いの端末の中

これらの情報は運営者のサーバーには送信されず、運営者が閲覧することもできません。選手の名前は利用者が自由に入力するものですが、実名など個人を特定できる情報は入力しないことをおすすめします。

3. アプリ内課金について

アプリ内課金（買い切りの商品・消費型の商品・自動更新サブスクリプション「RISE パス」）の決済は、Apple Inc. の App Store が行います。運営者は、クレジットカード番号などの支払い情報や Apple ID を受け取りません。本アプリは、購入が完了したことを確認するために、App Store から端末に届く取引情報（商品 ID・取引の状態）のみを端末内で利用します。Apple による情報の取り扱いは、Apple のプライバシーポリシー（https://www.apple.com/jp/legal/privacy/）をご確認ください。

4. 外部に送信される情報

  • 本アプリは、運営者のサーバーと通信しません。
  • App Store での購入・購入の復元の際、端末と Apple の間で通信が行われます。
  • 本アプリはゲームエンジン「Unity」（Unity Technologies）を使用しています。Unity の分析機能・クラッシュレポート機能は無効にしていますが、エンジンの仕組みとして、端末の種類・OS のバージョンなどの匿名の技術情報が Unity Technologies に送信される場合があります。詳しくは Unity のプライバシーポリシー（https://unity.com/legal/privacy-policy）をご確認ください。
  • 利用規約・プライバシーポリシーのページを開いた場合、GitHub Pages（GitHub, Inc.）がアクセスの記録を取得することがあります。

5. 第三者への提供

運営者は利用者の個人情報を収集していないため、第三者に提供することはありません。

6. お子さまの利用

本アプリは年齢を問わず遊べるよう作られており、お子さまの個人情報も収集しません。アプリ内課金を行う場合は、保護者の方の同意のもとで行ってください。iPhone の「スクリーンタイム」で購入を制限することもできます。

7. データの削除

本アプリを端末から削除すると、端末に保存されたゲームのデータはすべて削除されます（iCloud に保存したセーブは、同じ Apple ID で再インストールしたときに読み込めます。iCloud のデータは、iPhone の「設定」→ 自分の名前 →「iCloud」から管理・削除できます）。購入済みの買い切り商品と RISE パスの状態は、同じ Apple ID で再インストール後に「購入を復元」から取り戻せます（消費型の商品は復元できません）。

8. 本ポリシーの変更

法令の変更や本アプリの機能の追加（オンライン対戦など）に合わせて、本ポリシーを変更することがあります。重要な変更がある場合は、本アプリ内または本ページでお知らせします。新たに情報を収集する機能を加える場合は、事前に本ポリシーを改定します。
